### 4. 견적 2개 입력(구조 상이) + 견적 A 확정 — PASS

- 견적 "생성"은 계획상 API 전용(task 15)이고 화면은 상세 편집(task 20) 범위다. 두 견적의 shell을 브라우저 세션 쿠키로 `POST /api/projects/{id}/quotes`(pvId=서울W홀) 생성(201)한 뒤, 모든 항목 입력은 견적 상세 화면 UI로 수행했다.
- 견적 A(2026-10-20, 보장 200명) 5항목 UI 입력, 화면 소계/요약 관측:
  - 대관료(HALL_RENTAL) 1×12,000,000 = `12,000,000원` · 지역 평균 대비 `-40.0%`
  - 식대(MEAL) 200×180,000 = `36,000,000원` · `+140.0%`
  - 플라워(FLOWER, 필수✓/선택✓ 옵션) `1,500,000원` · `-23.1%`
  - 할인(DISCOUNT) `**-500,000원**(음수 자동 정규화 관측) · `-125.6%`
  - 부가세(VAT) `1,210,000원` · `-37.9%`
  - 요약: 최소총액(필수) `48,710,000원` / 옵션포함총액 `50,210,000원` / 1인당 `251,050원` — 손계산(12,000,000+36,000,000+1,210,000−500,000=48,710,000, +1,500,000=50,210,000, ÷200=251,050)과 일치.

## 이상 관측(코드 결함 아님, 조치 기록)

1. **공유 dev 서버의 신규 라우트 미감지(404)**: QA 시작 직후 `/projects/{id}`(대시보드)와 `/projects/{id}/budget`만 404. 원인은 전날 23:20에 기동된 공유 dev 서버의 파일 워처가 이후 생성된 라우트 파일(외장 SSD 볼륨)을 감지하지 못한 것. 파일 mtime 터치(내용 무변경)로 워처가 깨어나 두 라우트 모두 200 회복 — **서버 재기동 없이 해결**. 이후 플로우 전 단계에서 재발 없음.
2. **핫 리로드 직후 일시적 404 ×2**: 위 터치 직후 churn 중 `/api/projects/undefined/vendors` 404가 콘솔에 2회 기록됨(파라미터가 아직 리졸브되지 않은 마운트에서의 fetch). 목록은 곧바로 정상 렌더되어 사용자 플로우에는 영향 없었음. 재현 조건이 "워처 지연+리로드 경합"으로 좁혀지지 않아 남긴다 — 재발 시 tasks/vendors 화면 파라미터 리졸브 경로 확인 권장.
3. **계약 전환 후 견적 상세 배지 미갱신(사소)**: 계약 전환은 서버에서 견적을 CONFIRMED로 전이하지만, 견적 상세 화면은 전환 성공 후 견적을 리패치하지 않아 배지가 리로드 전까지 '임시'로 표시된다. 기능 오류는 아니고 개선 여지로만 기록한다.
